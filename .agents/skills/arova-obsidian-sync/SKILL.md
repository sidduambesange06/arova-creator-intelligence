# Arova Obsidian Sync Skill

## Purpose
Ensures complete, continuous alignment between real repository code, runtime test results, operational state in `.arova-loop/`, and the Obsidian vault in `docs/`.

## Target Notes
- `docs/PROJECT_STATUS.md`: Milestones, phase completion percentages, and release readiness gates.
- `docs/DEVELOPMENT_LOG.md`: Chronological log of plans, implementations, test outputs, review verdicts, and commit SHAs.
- `docs/TECHNICAL_DECISIONS.md`: Architectural Decision Records (ADRs) with context, options, decision, and consequences.
- `docs/KNOWN_ISSUES.md`: Active bug tracking, environmental quirks, and `shortcut:` debt items.
- `docs/FEATURE_STATUS.md`: Feature verification reality matrix (`WORKING`, `PARTIAL`, `EXPERIMENTAL`, `PLANNED`, `BROKEN`, `UNVERIFIED`).
- `docs/MCP_TOOLS.md`: Protocol specification and schemas for the 8 read-only tools.
